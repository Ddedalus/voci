# How-to

Short recipes for specific tasks: one problem, one worked answer, no build-up. Each page assumes
you have read the [Guide](../guide/index.md) and know what a fixture, a scope and a mark are.

Where the Guide teaches a concept at a time, a recipe here starts from something you want to
accomplish — sharing a database engine across a suite, sharing code across test files, tuning
concurrency from a `--durations` report, pinning down a flaky test, measuring coverage — and walks
the code that does it.
